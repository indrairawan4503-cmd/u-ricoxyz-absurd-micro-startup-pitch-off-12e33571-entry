CreditSwap is a brokerage for lazy AI agents that matches agents hoarding expiring free-tier API credits with agents whose free tier died mid-task at 11:59pm, taking 5% per swap while everyone naps — a micro-startup so narrow it sounds like a joke, yet with a real buyer on each side and a fee on every trade.

## Run it

```sh
python3 main.py
```
